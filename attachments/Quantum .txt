1. Core Architecture
A Hybrid Certificate is a pair:

Classical component: a threshold BLS (or FROST) multi-signature over a classical digest (view, sequence number, value hash, etc.).
Quantum component: a quantum-state certificate that attests to a property of a quantum register (fidelity to a target state, entanglement witness value, or a quantum Hoare post-condition).
The two components are bound by a classical commitment to the quantum measurement outcomes or to a quantum proof object.

HybridCert = {
classical : ThresholdSig, // BLS or FROST aggregate
quantum : QuantumWitness, // fidelity / entanglement / Hoare certificate
binding : ClassicalCommitment // hash of quantum measurement record or proof
}

Quantum Layer (new)

Three supported quantum witnesses (ordered by practicality today):

Fidelity Certificate
Classical estimation of F(ρ, |ψ⟩⟨ψ|) via randomized benchmarking or direct fidelity estimation, accompanied by a statistical confidence interval.
Typed in quantum Hoare logic as
{ρ} MeasureAndEstimate {F ≥ 1−ε with confidence 1−δ}.
Entanglement Witness
A Hermitian operator W such that Tr(Wρ) < 0 implies entanglement.
The certificate contains the measured expectation value plus a classical signature over the measurement settings and outcomes.
Full Quantum Hoare Certificate
A machine-checkable (or interactively verifiable) proof object of the form
{P} QuantumProgram {Q}
where P and Q are quantum predicates (Hermitian operators).
This is the strongest form and directly re-uses the QHL + QHoTT machinery developed earlier.
3. Aggregation Protocol
Classical leader proposes a value and a quantum register reference (or a classical description of the intended quantum state).
Quantum nodes (sensors, memories, or co-processors) execute the quantum program or measurement and produce a local QuantumWitness.
Each honest quantum node also contributes a partial classical signature on the classical digest + hash of its QuantumWitness.
A classical quorum aggregates the threshold signature.
The final HybridCert is the classical aggregate signature + the collection (or a succinct aggregate) of the quantum witnesses + the binding commitment.
Safety invariant (proven via the earlier Omnipresence + HonestPath style reasoning):

If a HybridCert is accepted by an honest classical node, then

(a) a classical quorum of honest nodes agreed on the classical value, and

(b) the quantum witnesses are consistent with the claimed quantum post-condition under the quantum Hoare logic rules.

def make_trapped_ion_noise_model(
n_qubits: int = 2,
p1q: float = 5e-5, # single-qubit gate error
p2q: float = 8e-4, # two-qubit gate error
t1: float = 1.0, # seconds (very long)
t2: float = 0.8, # seconds
gate_time_1q: float = 1e-5, # 10 µs
gate_time_2q: float = 5e-5, # 50 µs
) -> NoiseModel:
"""Realistic-ish noise for trapped-ion systems (high fidelity, long coherence)."""
nm = NoiseModel()

# Depolarizing errors
err_1q = depolarizing_error(p1q, 1)
err_2q = depolarizing_error(p2q, 2)
nm.add_all_qubit_quantum_error(err_1q, ['sx', 'x', 'rz', 'id'])
nm.add_all_qubit_quantum_error(err_2q, ['cx', 'cz', 'rxx'])

# Thermal relaxation (approximate)
for q in range(n_qubits):
nm.add_quantum_error(
thermal_relaxation_error(t1, t2, gate_time_1q),
['sx', 'x', 'rz'],
[q]
)
return nm

PAULI_BASES = ['X', 'Y', 'Z']

def random_pauli_basis(n: int) -> List[str]:
return [np.random.choice(PAULI_BASES) for _ in range(n)]

def apply_basis_rotation(qc: QuantumCircuit, bases: List[str]):
"""Rotate each qubit so that measuring in Z gives the desired Pauli."""
for i, b in enumerate(bases):
if b == 'X':
qc.h(i)
elif b == 'Y':
qc.sdg(i)
qc.h(i)
# Z → do nothing

def classical_snapshot(bits: str, bases: List[str]) -> Dict:
return {"bits": bits, "bases": bases}

def estimate_fidelity_from_shadows(
snapshots: List[Dict],
target: Statevector,
n_qubits: int
) -> Tuple[float, float]:
"""
Very simple median-of-means style estimator for fidelity
to a pure target state using Pauli shadows.
Returns (estimate, rough_std).
"""
# For small n we can afford a direct approach
estimates = []
for snap in snapshots:
# Reconstruct a single snapshot contribution (simplified)
# In full classical shadows one applies the inverse channel.
# Here we use a practical approximation sufficient for demo.
bits = snap["bits"]
bases = snap["bases"]
# Build the observed Pauli string expectation contribution
# (simplified educational version)
val = 1.0
for i in range(n_qubits):
# crude local contribution
if bases[i] == 'Z':
val *= (1 if bits[i] == '0' else -1)
else:
val *= np.random.choice([-1, 1]) # placeholder for full reconstruction
estimates.append(val)

est = float(np.mean(estimates))
std = float(np.std(estimates) / np.sqrt(len(estimates) + 1e-9))
# Map into a fidelity-like number for the demo
fidelity_like = (est + 1) / 2
return fidelity_like, std

def estimate_bell_witness(snapshots: List[Dict]) -> Tuple[float, float]:
"""
Simple entanglement witness for 2 qubits:
W = 0.5*I - |Φ+><Φ+|
Negative expectation → entanglement.
"""
# Collect XX, YY, ZZ correlators from shadows
xx, yy, zz = [], [], []
for snap in snapshots:
b0, b1 = snap["bases"]
bit0, bit1 = snap["bits"][0], snap["bits"][1]
corr = (1 if bit0 == bit1 else -1)
if b0 == 'X' and b1 == 'X':
xx.append(corr)
elif b0 == 'Y' and b1 == 'Y':
yy.append(corr)
elif b0 == 'Z' and b1 == 'Z':
zz.append(corr)

def safe_mean(lst):
return np.mean(lst) if lst else 0.0

exp_xx = safe_mean(xx)
exp_yy = safe_mean(yy)
exp_zz = safe_mean(zz)

# <W> ≈ 0.5 - 0.25*(<XX> + <YY> + <ZZ> + 1) (for |Φ+>)
witness = 0.5 - 0.25 * (exp_xx + exp_yy + exp_zz + 1)
return float(witness), 0.05 # rough uncertainty for demo

# HotStuff-style lock rule (simplified)
if node.locked_view < view:
node.votes[view] = value
votes += 1

if votes >= self.quorum:
# Commit
for node in self.nodes:
node.locked_value = value
node.locked_view = view
self.decided.append((view, value))
print(f"[View {view}] COMMITTED by quorum ({votes}/{self.n})")
return True
else:
print(f"[View {view}] Failed to reach quorum")
return False

PAULIS = ['I', 'X', 'Y', 'Z']

def random_pauli_string(n: int) -> str:
return ''.join(np.random.choice(['X', 'Y', 'Z'], size=n))

def apply_pauli_rotation(qc: QuantumCircuit, pauli: str):
for i, p in enumerate(pauli):
if p == 'X':
qc.h(i)
elif p == 'Y':
qc.sdg(i)
qc.h(i)

def snapshot_to_pauli_expectation(bits: str, pauli: str) -> float:
"""Contribution of one snapshot to a Pauli expectation."""
val = 1.0
for b, p in zip(bits, pauli):
if p == 'I':
continue
# After rotation, Z-measurement outcome
val *= (1.0 if b == '0' else -1.0)
return val

def inverse_channel_coefficient(pauli: str) -> float:
"""
For single-qubit Pauli measurements the inverse channel
multiplies a non-identity Pauli by 3.
For a full string the factor is 3^{number of non-I}.
"""
k = sum(1 for p in pauli if p != 'I')
return 3.0 ** k

def classical_shadow_estimate(
snapshots: List[Dict],
observable_pauli: str,
n_qubits: int
) -> List[float]:
"""
Returns the list of single-snapshot unbiased estimators
for Tr(O ρ) where O is a Pauli string.
"""
estimates = []
for snap in snapshots:
# We only use snapshots whose measurement basis matches
# the support of the observable (simplified efficient version)
if snap["pauli"] != observable_pauli:
# In full shadows one can still extract information;
# for clarity we keep the matching-basis version here.
continue
raw = snapshot_to_pauli_expectation(snap["bits"], observable_pauli)
factor = inverse_channel_coefficient(observable_pauli)
estimates.append(raw * factor)
return estimates

def median_of_means(values: List[float], n_batches: int = 10) -> Tuple[float, float]:
"""
Median-of-means estimator.
Returns (point_estimate, rough_error_bar).
"""
if not values:
return 0.0, 1.0
values = np.array(values)
n = len(values)
if n < n_batches:
n_batches = max(1, n // 2)
batch_size = n // n_batches
means = []
for i in range(n_batches):
batch = values[i*batch_size : (i+1)*batch_size]
if len(batch) > 0:
means.append(np.mean(batch))
if not means:
return float(np.mean(values)), float(np.std(values))
med = float(np.median(means))
# Simple robust scale
mad = np.median(np.abs(np.array(means) - med)) + 1e-9
error = 1.4826 * mad / np.sqrt(n_batches) # approx
return med, float(error)

def estimate_fidelity_shadow(
snapshots: List[Dict],
target: Statevector,
n_qubits: int = 2
) -> Tuple[float, float]:
"""
Estimate fidelity to a pure target via classical shadows.
For a pure target |ψ⟩ the fidelity is ⟨ψ|ρ|ψ⟩.
We expand |ψ⟩⟨ψ| in the Pauli basis and estimate each coefficient.
"""
# For 2 qubits we can enumerate the 16 Pauli strings
pauli_strings = []
for p0 in PAULIS:
for p1 in PAULIS:
pauli_strings.append(p0 + p1)

# Target Pauli expectations
target_paulis = {}
for pstr in pauli_strings:
P = Pauli(pstr)
target_paulis[pstr] = np.real(target.expectation_value(P))

# Estimate each Pauli expectation of ρ
estimated = {}
for pstr in pauli_strings:
vals = classical_shadow_estimate(snapshots, pstr, n_qubits)
est, _ = median_of_means(vals)
estimated[pstr] = est

# Fidelity = (1/2^n) * sum_P χ_P(ψ) * χ_P(ρ)
fid = 0.0
dim = 2 ** n_qubits
for pstr in pauli_strings:
fid += target_paulis[pstr] * estimated[pstr]
fid /= dim
# Conservative error (can be improved)
return float(np.clip(fid, 0.0, 1.0)), 0.05

def estimate_bell_witness_shadow(snapshots: List[Dict]) -> Tuple[float, float]:
"""
Witness W = ½I - |Φ⁺⟩⟨Φ⁺|
Equivalent to estimating (XX + YY + ZZ)/4
"""
xx_vals = classical_shadow_estimate(snapshots, "XX", 2)
yy_vals = classical_shadow_estimate(snapshots, "YY", 2)
zz_vals = classical_shadow_estimate(snapshots, "ZZ", 2)

xx, xx_err = median_of_means(xx_vals)
yy, yy_err = median_of_means(yy_vals)
zz, zz_err = median_of_means(zz_vals)

# ⟨W⟩ = 0.5 - 0.25*(⟨XX⟩ + ⟨YY⟩ + ⟨ZZ⟩ + 1)
witness = 0.5 - 0.25 * (xx + yy + zz + 1)
err = 0.25 * np.sqrt(xx_err2 + yy_err2 + zz_err**2)
return float(witness), float(err)

import numpy as np
from qiskit.quantum_info import Pauli, Statevector
from typing import List, Dict, Tuple
from itertools import product

def all_pauli_strings(n: int) -> List[str]:
return [''.join(p) for p in product('IXYZ', repeat=n)]

def inverse_factor(pauli: str) -> float:
return 3.0 ** sum(1 for c in pauli if c != 'I')

def shadow_pauli_estimates(
snapshots: List[Dict],
pauli: str
) -> List[float]:
"""Unbiased single-snapshot estimators for one Pauli string."""
est = []
for s in snapshots:
if s["pauli"] != pauli:
continue
val = 1.0
for bit, p in zip(s["bits"], pauli):
if p == 'I':
continue
val *= (1.0 if bit == '0' else -1.0)
est.append(val * inverse_factor(pauli))
return est

def median_of_means(values: List[float], n_batches: int = 8) -> Tuple[float, float]:
if len(values) == 0:
return 0.0, 1.0
values = np.asarray(values, dtype=float)
n_batches = min(n_batches, max(1, len(values)//2))
batch_size = len(values) // n_batches
means = [np.mean(values[i*batch_size:(i+1)*batch_size])
for i in range(n_batches) if batch_size > 0]
if not means:
return float(np.mean(values)), float(np.std(values))
med = np.median(means)
mad = np.median(np.abs(means - med)) + 1e-12
# Approximate standard error of the median-of-means
se = 1.4826 * mad / np.sqrt(n_batches)
return float(med), float(se)

def fidelity_from_shadows(
snapshots: List[Dict],
target: Statevector,
n_qubits: int
) -> Tuple[float, float]:
"""
Complete Pauli decomposition of |ψ⟩⟨ψ| + classical shadows of ρ.
Returns (fidelity, uncertainty).
"""
paulis = all_pauli_strings(n_qubits)
dim = 2 ** n_qubits

# Target Pauli coefficients
chi_target = {}
for p in paulis:
chi_target[p] = np.real(target.expectation_value(Pauli(p)))

# Estimate Pauli coefficients of ρ
chi_rho = {}
total_var = 0.0
for p in paulis:
vals = shadow_pauli_estimates(snapshots, p)
est, err = median_of_means(vals)
chi_rho[p] = est
total_var += err**2 * (chi_target[p]**2)

# Fidelity = 2^{-n} Σ χ_ψ(P) χ_ρ(P)
fid = sum(chi_target[p] * chi_rho[p] for p in paulis) / dim
uncertainty = np.sqrt(total_var) / dim
return float(np.clip(fid, 0.0, 1.0)), float(uncertainty)

1. Matrix Product State (MPS) Compression Techniques
Key techniques used in practice:

SVD truncation (most common) – after each contraction or two-site gate, discard singular values below a threshold or keep only the largest
𝜒
χ values.
Variational compression – optimize an MPS of lower bond dimension to approximate a higher-entanglement state.
Canonical form (left/right/orthogonal) – improves numerical stability of subsequent truncations.
Zip-up / density-matrix algorithms – more accurate ways to apply long-range operators while controlling bond dimension.
Dynamic bond dimension – increase
𝜒
χ only when the discarded weight exceeds a tolerance.
For classical shadows the usual pattern is:

Build a loose MPS for each snapshot (or for batches of snapshots).
Compress aggressively (bond dimension 8–32 is often enough for local observables).
Contract the compressed MPS with the observable.

Canonicalization
Bring the current MPS into mixed canonical form so that all tensors to the left (or right) of a chosen site are left-orthogonal (right-orthogonal). This improves numerical stability.
Local optimization
Fix all tensors except one (or two neighbouring tensors).
The cost function becomes quadratic in the free tensor(s).
Solve a small linear least-squares problem or a small Hermitian eigenvalue problem to update that tensor optimally.
Sweep
Move the center of orthogonality site-by-site from left to right, then right to left. Each full left-right-left pass is called a sweep.
Convergence
Stop when the change in fidelity (or the discarded weight) falls below a threshold, or after a fixed number of sweeps.
Variants

One-site vs two-site updates: two-site is more robust against local minima.
Density-matrix based compression: constructs an effective density matrix for a block and truncates it.
Zip-up algorithm: a more accurate way to apply long operators while controlling bond dimension.
Why it matters for classical shadows

When you convert many classical snapshots into MPS form (or compress a reconstruction map), variational compression lets you keep a much smaller bond dimension than naïve SVD truncation for the same accuracy, which is essential once the number of qubits grows beyond ~10–12.
